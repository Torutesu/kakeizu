# 触って確かめる手順（20分）

公開した環境を、実際に使う流れで一通り触るための手順。
細かい確認項目の一覧は [QA_CHECKLIST.md](./QA_CHECKLIST.md)、自動で流す分は `pnpm qa:live`。

**本物の戸籍は使わず、同梱の見本で試す。**
見本は架空の家族（法務省の記載例で慣例の「甲野」家）で、
`e2e/live/fixtures/koseki-sample/` にある（`node scripts/make-sample-koseki.mjs` で作り直せる）。

| ファイル | 中身 |
|---|---|
| `a_zenbu_jiko.pdf` | 現在の戸籍（全部事項証明・横書き・1枚）。筆頭者 甲野太郎 |
| `b_kaisei_1.png` 〜 `_3.png` | 改製原戸籍（縦書き・和暦は漢数字）。**3枚で1通**。筆頭者 甲野義太郎 |

---

## 0. 用意するもの

- 公開した環境のURL
- **ブラウザを2つ**（通常のウィンドウとシークレットウィンドウ）
- 利用者2人: **Aさん＝管理者**（最初に組織を作った人）、**Bさん＝作業者**（Aさんが「メンバー管理」から招待）

---

## 1. 取り込みと読み取り（8分）

Aさんで案件を作り、開く。

| # | 操作 | こうなれば正しい |
|---|---|---|
| 1 | 左の「戸籍PDFをアップロード」から `a_zenbu_jiko.pdf` を選び、「1件を解析」 | 1〜2分で家系図が出る |
| 2 | 読み取った人物を見る | 下の「正解（A）」の4人が出ている |
| 3 | もう一度開き、`b_kaisei_1〜3.png` を**3枚まとめて**選ぶ | 押す前に「3枚をまとめて通しで読み取ります」、各行に「1/3枚目」〜「3/3枚目」 |
| 4 | ↑↓で順番を入れ替えて、元に戻す | 枚数の表示が追従する |
| 5 | 「3件を解析」 | 左の一覧に「1通3枚中 1枚目」と出る（3枚で1回の読み取り） |
| 6 | 家系図を見る | 下の「正解（B）」の5人が加わる |
| 7 | **甲野太郎**を見る | 2つの戸籍の両方に出てくるので、**1人にまとまっている**。2人に分かれて残った場合は、人物を選んだときの「統合」ボタンに候補の数が出る |
| 8 | **甲野次郎**のカード | 没年月日がわざと汚してあるので、**赤字で「読み取り失敗: 没年月日」** |
| 9 | 画像をコピーして、取り込み画面で Ctrl/⌘+V | 貼り付けで一覧に加わる |

## 2. 編集（4分）

| # | 操作 | こうなれば正しい |
|---|---|---|
| 1 | 甲野義太郎のカード | **享年72**（数え年）。梅子は**享年74**、太郎は**享年82** |
| 2 | 人物をダブルクリックして名前を変え、保存 | 右上が「保存中...」→「保存済み」 |
| 3 | 人物をドラッグして動かす | 動いた位置のまま残る（再読み込みしても） |
| 4 | Ctrl/⌘+Z | 直前の操作が取り消される |
| 5 | 甲野次郎を開いて没年月日を入れ、保存 | 赤字が消える |
| 6 | 別の人物（赤字なし）を開いて、何も変えずに保存 | 何も変わらない |

## 3. 2人で同時に触る（5分）

シークレットウィンドウでBさんとしてログインし、同じ案件を開く。

| # | 操作 | こうなれば正しい |
|---|---|---|
| 1 | Bさんが開く | Aさんの画面の上部に「（Bさん）さんも開いています」 |
| 2 | Bさんが人物をダブルクリック | Aさんの画面で、そのカードに色枠と「○○さんが編集中」 |
| 3 | Bさんが名前を1文字ずつ打つ | **Aさんの画面のカードが、打つそばから変わる** |
| 4 | Bさんがキャンセル | Aさんの画面が元に戻る |
| 5 | AさんとBさんが**別々の人物**をほぼ同時に直して保存 | **両方の変更が残る**（片方が消えたら不具合） |
| 6 | Bさんのウィンドウで通信を切る（DevTools → Network → Offline）→ 編集 | 「オフライン（未送信）」になり、編集は続けられる |
| 7 | 通信を戻す | 自動で送られ「保存済み」。Aさんの画面にも入る |

## 4. 出力（3分）

| # | 操作 | こうなれば正しい |
|---|---|---|
| 1 | 右上「書き出し」→ PDF → A4・1枚に収める | 小さすぎる場合は警告と、A3・分割の提案 |
| 2 | 分割で書き出す | PDFが落ちてくる。ページ数と貼り合わせの目安が入っている |
| 3 | 「書き出し」→ Excel | 氏名（原文）・生年月日（原文）・読み取り失敗・本籍の列がある |
| 4 | 人物を選び、右の「出典」を押す | 読み取り元の原本が開く |
