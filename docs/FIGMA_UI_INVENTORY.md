# Figma書き出し対象

現行実装 `694f3b1` を基準にした、画面と状態の一覧。2026-09-30作成。
Figmaに45画面・主要状態を作成済み。下の対象一覧は調査時の候補を含み、すべての細かな操作状態を個別フレーム化したものではない。

保存先: [Kakeizu / 現行UI](https://www.figma.com/design/j4QJ4oerH1XvBSSQ7JFEi4/Kakeizu?node-id=12-17)

## 作成方針

- 現行画面を編集可能なテキスト・ベクター・コンポーネントで再現する。
- 現行画面と今後の修正案を分け、比較できるようにする。
- 同梱の架空の甲野家を用い、実際の利用者情報・鍵・パスワードは含めない。
- 状態を再現した画面はその旨を明記する。実環境の検証結果と混同しない。
- フォントは `app/layout.tsx` のGeistを基準に、日本語の表示書体も確認する。
- ボタン、入力欄、人物カード、ヘッダーなどは共通コンポーネントにする。
